# News Genie

News Genie is a Python Flask-based intelligent news web application designed to provide a seamless and interactive news browsing experience. It features voice-enabled navigation, dark mode support, and category-based content exploration through a responsive user interface.

## Features

* Voice-enabled navigation
* Dark mode and light mode support
* Category-wise news browsing
* Responsive user interface
* Interactive user experience

## Tech Stack

* Python
* Flask
* HTML
* CSS
* JavaScript

## Project Overview

News Genie enables users to explore news content efficiently with an intuitive interface, enhanced accessibility, and smooth interaction.

## Future Enhancements

* Personalized recommendations
* User authentication
* Saved articles
* Advanced search filters
